# Trafikte Korna Etik Mahkemesi

## Resmi Statü

Bu yazılım, karayollarında korna çalma eyleminin ahlaki, kozmik ve akustik meşruiyetini yargılayan **bağımsız üst mahkemedir**.

Yargıçlar:
- bir Python yorumlayıcısı
- rastgele sayı üreteci
- evrenin sabır katsayısı

Kararlar kesindir. Temyiz yoktur. Korna çalındıktan sonra pişmanlık, delil olarak kabul edilmez.

## Kurulum

```bash
python3 mahkeme.py
```

Başka bir şey kurmanıza gerek yok. Adalet sade olmalıdır. Sade olmayan adalet, yanlış şeritte ilerleyen bir kamyondur.

## Kullanım

Program size durumu sorar. Siz anlatırsınız. Mahkeme düşünür (yaklaşık 0.8 saniye). Sonra karar okunur.

Örnek kararlar:
- **MEŞRU KORNA** — önündeki araç yeşil ışıkta şiir yazıyordu.
- **AŞIRI KORNA** — sesiniz üç mahalleyi uyandırdı, biri rüyasında vergi ödedi.
- **KORNA DEĞİL ÇIĞLIK** — bu bir ulaşım eylemi değil, bir varoluş çığlığıdır.

## Bilimsel Dayanak

Korna, teorik olarak:
1. bir uyarıdır
2. bir duygudur
3. bazen de yanlışlıkla dirseğe gelen bir felakettir

Mahkeme bu üçlüyü tartar. Tartı bozuk olabilir. Bu, adaletin bir parçasıdır.
